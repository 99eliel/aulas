# Guia de Aulas — Informática Básica

PWA para condução de um curso de 20 encontros (30 horas).

## Recursos
- 20 roteiros completos: Windows, Internet, Word, IA, Excel e projeto final
- TypingClub integrado à rotina das aulas
- acompanhamento de PPM e precisão (inicial, intermediário e final)
- checklist por aula
- anotações locais
- cronômetro de 1h30
- progresso do curso
- funcionamento offline via Service Worker
- dados armazenados no navegador via localStorage

## Publicar no GitHub Pages
No repositório, abra **Settings > Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.

Depois o app ficará disponível no endereço do GitHub Pages do repositório.

## Observação
Nesta primeira versão os dados ficam somente no dispositivo/navegador utilizado. Uma versão futura pode usar Firebase para sincronizar várias turmas e dispositivos.
